PR 7：TTS 语音合成功能
标题: TTS speech synthesis for translated text

功能描述
新增 TTS（文字转语音）功能，翻译结果会自动朗读出来，实现真正的"同声传译"体验,用户也可以随时关闭语音朗读。
新增元素：
1.控制面板新增 「🔊 语音」按钮，点击切换开启/关闭
2.顶部状态栏新增 「🔊 朗读中」指示器，朗读时闪烁
3.朗读队列自动管理，多条翻译不会重叠

实现思路:
1.使用浏览器内置的 SpeechSynthesis API（免费，无需额外配置）
2.TTSManager 类维护朗读队列，防止多条翻译同时朗读导致冲突
3.根据目标语言自动选择对应语音（zh-CN → 中文女声，en-US → 英语女声，ja-JP → 日语女声等）
4.切换目标语言时，TTS 语言同步更新
5.停止录音或重置会话时自动停止朗读并清空队列

测试方式:
1.启动服务后，用 Chrome 浏览器打开页面
2.确认控制面板显示「🔊 语音」按钮（绿色高亮表示开启）
3.说一句英语，确认翻译出现后浏览器自动朗读中文翻译
4.快速说多句话，确认朗读排队播放不会重叠
5.顶部出现「🔊 朗读中」闪烁指示器
6.点击「🔇 静音」按钮，再说一句话，确认不再朗读
7.再次点击「🔊 语音」恢复朗读
8.切换目标语言为日语/韩语，确认朗读语音变为对应语言
